# AGENTS.md

All project instructions for AI coding agents live in [CLAUDE.md](CLAUDE.md). Read it in full before starting any task and follow it as if it were written here.

- **Guidelines**: [CLAUDE.md](CLAUDE.md) holds the Laravel Boost guidelines. Run `php artisan boost:update` to refresh them; don't copy them into this file.
- **Skills**: `.claude/skills/`. When a task matches a skill, read its `SKILL.md` before writing code.
- **MCP server**: Laravel Boost runs via `php artisan boost:mcp` (see `.mcp.json`).
